claudesphere

Every prompt you send to Claude Code becomes one dot. Dots are grouped by project and theme, and time runs from the centre (oldest) to the surface (newest). Faint curves join prompts from the same session.

Synthetic demo data, same size as the author's real sphere. Nothing on this page comes from real prompts.

Try it

  1. Drag to rotate, scroll or pinch to zoom.
  2. Hover or tap a dot to see its fields.
  3. Press "What the fields mean" for the full legend.
  4. Drag across the strip below to pick a date range.
