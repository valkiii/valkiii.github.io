XGO-Duck on a Pi

Can a 3D-printed duck learn to walk on a Pi Zero?

When
October 2026
Status
building
Made with
Raspberry Pi Zero 2W, Feetech bus servos, ONNX policies, Python

The duck walks with reinforcement-learned policies. Swapping its controller for a Pi means rewriting the loop that talks to the servos, not the brain.

15servos
50 Hzwalking policy
34tests in simulation

How it works

  1. 1
    Port. The microcontroller sketch rewritten in Python, behind the same interface, so the upstream code runs unchanged.
  2. 2
    Simulate. A simulated servo bus and robot, so everything is tested before the hardware arrives.
  3. 3
    Guide. A step-by-step setup wizard: parts, servo IDs, wiring scan, SSH, IMU axes, calibration.
