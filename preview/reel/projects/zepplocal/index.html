ZeppLocal

Can I keep my watch data without trusting another app?

When
October 2026
Status
prototype
Made with
Python, SQLite, pywebview, keyring

Third-party sync apps want your watch account. I wanted the same features with code small enough to read in an evening.

1server it talks to: Zepp's own
0CDNs, map tiles or telemetry

How it works

  1. 1
    Sync. Sign in once; raw responses are stored, so parsing can be redone later.
  2. 2
    Store. Everything lands in one SQLite file on the Mac.
  3. 3
    Guard. A test fails the build if any code tries to reach a host other than Zepp's.

What I learned

Privacy you can test is worth more than privacy you promise.
