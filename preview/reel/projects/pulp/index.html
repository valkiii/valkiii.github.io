After Precog, the obvious next question was a game. Then a harder one: what if you only had your eyes?

60fps canvas
13 + 7calibration and validation dots
0servers: it all runs in the browser

How it works

  1. 1
    Hands. MediaPipe's hand landmarker runs in the browser. Only fast swipes cut; slow movement doesn't.
  2. 2
    Eyes. A face mesh with irises, calibrated each session on 13 dots and checked on 7 more.
  3. 3
    Fit. A small ridge regression maps eye features to the screen; leave-one-dot-out cross-validation picks the model.
  4. 4
    Cut. In eye mode a cut is a quick saccade flick or a dwell. Blinks are filtered out.

What I learned

Moving from Python to the browser removed a whole class of driver and GPU problems, and gave a smooth 60 fps.
Gaze is noisy. Calibration you can verify matters more than a clever model.
