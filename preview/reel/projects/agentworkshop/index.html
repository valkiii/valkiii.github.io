Agent demos usually start with an API key and a credit card. This one runs offline on a laptop, so everyone in the room can follow every step.

4steps: perceive, extract, decide, act
0API keys

How it works

  1. 1
    Perceive. Read blog and RSS sources for recent articles.
  2. 2
    Extract. Pull the text and summarise it with a small local model.
  3. 3
    Decide. Judge each summary against an interest written in plain English.
  4. 4
    Act. Compile the keepers into an EPUB with tags and a comprehension quiz.

What I learned

Small local models are enough to teach the loop. The loop is the lesson.
