Local Voice Transcriber

Can dictation be private and pretty?

When
September 2025
Status
shipped
Made with
Python, OpenAI Whisper (local)

Code on GitHub ↗

Speech to text shouldn't need an account. Whisper runs fine on a laptop.

How it works

  1. 1
    Record. Pick a microphone, click the ball; it pulses as you speak.
  2. 2
    Transcribe. Whisper runs locally; nothing leaves the machine.
  3. 3
    Keep. Each transcript is saved with a timestamp for its name.
