A local Omi

Can a wearable assistant work with no cloud at all?

A fully local companion app for the Omi wearable. Bluetooth, on-device transcription and an on-device model, no API keys.

Code on GitHub ↗

0cloud services

The idea

A device that listens all day should not send what it hears anywhere.

How it works

  1. Fork

    Start from an open-source Omi app and strip every cloud call.

  2. Transcribe

    On-device speech recognition on the iPhone.

  3. Think

    An on-device Gemma model behind the same interface the cloud model used.

What I learned

  • Removing the cloud is mostly finding every place that assumed it.
