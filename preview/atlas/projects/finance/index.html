Household finance dashboard

Where does the money go, month by month?

A private dashboard for bank transactions, investments, pension, mortgage and Dutch tax rules, served from a Raspberry Pi and reachable only over Tailscale.

0personal data in the code repository
1HTML page, phone first

The idea

Banking apps show balances. I wanted trends: every category month by month, what changed, and why a number is what it is.

How it works

  1. Ingest

    Bank and broker exports are parsed and categorised with rules I can edit from the page.

  2. Explain

    Every number opens a panel that shows how it is worked out.

  3. Stay private

    The server refuses to listen on public interfaces; the code repository holds no data.

What I learned

  • Re-categorising in the page beats editing rules in a file. You fix things when you see them.
