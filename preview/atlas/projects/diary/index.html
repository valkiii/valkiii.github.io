The Diary

What if a paper notebook wrote back?

Tom Riddle's diary on a Supernote e-ink tablet. Write and rest your pen; your ink fades into the page and an answer writes itself back, letter by letter.

Code on GitHub ↗

60–85 msto add one pen line on the tablet
8–40 sbefore the reply fades

The idea

A port of Maxime Rivest's riddle to the Supernote Manta. The magic is that it feels like paper, not like a chat window.

How it works

  1. Read

    The tablet's handwriting recognition reads your strokes.

  2. Drink

    Your ink fades while a small bridge asks a model for Tom's reply.

  3. Write

    The answer appears stroke by stroke in a flowing hand, lingers, and fades away.

What I learned

  • The tablet blocks plain HTTP from plugins, so the plugin speaks raw sockets natively.
