Risk engine

Can agents learn to conquer the world?

The board game Risk as a Python engine, with the full map, turn logic and AI agents that play each other.

Code on GitHub ↗

The idea

Before Connect 4, I wanted an environment with more going on: territories, dice and alliances.

How it works

  1. Map

    Every territory and continent as an adjacency graph.

  2. Rules

    Reinforcement, attack and fortification, turn by turn.

  3. Agents

    Simple AI players and a map that draws the state of the game.
